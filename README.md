# Reading App 📚

An iOS app for teaching kids to read, inspired by Bob Books.

Perfect for children ages 4-6 who are learning to read simple words.

## Features

- 📖 Progressive phonics-based books starting with simple CVC words
- 🔊 Tap any word to hear it pronounced
- 📣 Read-aloud mode for the entire page
- 🎉 Celebration animations when completing books
- 🎨 Playful, kid-friendly design with rounded fonts
- ✨ Interactive bounce animations

## Screenshots

The app includes:
- A colorful library view showing all available books
- An interactive reading interface with large, tappable words
- Text-to-speech support for learning pronunciation
- Celebrations to keep kids motivated
